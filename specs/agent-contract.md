# agent-contract.md

> **Status**: v1.0.0. Supersedes T02-pre stub. Populated in T06.

Every Task-spawned subagent — whether a reviewer, a builder, a doctor, or an advisor — carries an
explicit identity, scope, memory binding, and budget. This spec defines the **input envelope** the
parent agent MUST send when spawning, and the **return envelope** the child MUST emit. Together they
are the machine-readable contract that lets traces correlate, RBAC hold, budgets stop runaway, and
parallel review (see [parallel-review.md](parallel-review.md)) stay auditable.

---

## 1. Why a formal envelope

- Traces: `agent_id` + `parent_agent_id` + `trace_id` reconstruct the full spawn tree in OTel.
- Memory: `bank_id` binds the child to the correct Hindsight scope (see
  [memory-hierarchy.md](memory-hierarchy.md)).
- RBAC: at deploy time (T18 LangGraph workflows), `scope.write_paths` maps 1:1 to a Kubernetes
  ServiceAccount's allowed paths. A child that tries to write outside `scope.write_paths` is an
  `untracked_state_mutation` failure (see [agentic-failures.md](agentic-failures.md)).
- Budgets: runaway loops (`infinite_loop`) are caught deterministically by the harness, not by
  hoping the model stops.
- Verdicts: every return carries a verdict per [verdict-contract.md](verdict-contract.md), so the
  parent's triage logic is uniform across agent types.

## 2. Input envelope

Required at spawn. The parent agent constructs it; the harness that implements the Task tool
validates it against the JSON Schema (§5) before the child's prompt is sent.

```json
{
  "agent_id": "0196f34a-8c7e-7b2f-9d01-3e8a9b4c2f11",
  "agent_type": "reviewer",
  "parent_agent_id": "0196f34a-1100-7a00-8000-000000000001",
  "trace_id": "0af7651916cd43dd8448eb211c80319c",
  "scope": {
    "project": "consumer-c-legacy",
    "change_id": "module-1-ingredients-implementation",
    "read_paths": ["apps/api/src/ingredients/**", "packages/types/src/**"],
    "write_paths": []
  },
  "memory": {
    "bank_id": "consumer-c-legacy",
    "recall_depth": 5
  },
  "brief": "Acceptance Auditor for module-1-ingredients-implementation. Check AC 1..12 in openspec/changes/module-1-ingredients-implementation/specs/ingredients.md one-for-one against the diff on branch feat/ingredients-impl. Return verdict per verdict-contract.md.",
  "budget": {
    "max_tokens": 50000,
    "max_wall_seconds": 300,
    "max_tool_calls": 40
  }
}
```

### 2.1 Field reference

| Field | Type | Req | Notes |
|---|---|---|---|
| `agent_id` | UUIDv7 string | yes | Generated by the harness at spawn. Carries wall-clock ordering. |
| `agent_type` | enum string | yes | One of `reviewer`, `builder`, `doctor`, `advisor`, `retro`, `dispatcher`, `custom`. |
| `parent_agent_id` | UUIDv7 or null | yes | `null` iff the agent was spawned by a human (root of tree). |
| `trace_id` | OTel 16-byte hex | yes | Propagates via W3C trace context; set by the root. |
| `scope.project` | string | yes | Project slug as it appears in `specs/projects-registry.md`. |
| `scope.change_id` | string or null | yes | OpenSpec change id, or `null` for non-OpenSpec tasks (e.g. a cross-cutting doctor run). |
| `scope.read_paths` | string[] | yes | Glob patterns the child is allowed to read. Harness may enforce. |
| `scope.write_paths` | string[] | yes | Glob patterns the child is allowed to write. Empty list = reviewer. |
| `memory.bank_id` | string | yes | Hindsight bank; see [memory-hierarchy.md](memory-hierarchy.md) §2. |
| `memory.recall_depth` | int ≥0 | yes | `top_k` for the bootstrap recall call. 0 disables recall. |
| `brief` | string | yes | Free-form task description. LEAN: what + why + return shape expected. |
| `budget.max_tokens` | int ≥1 | yes | Hard cap on total output tokens. |
| `budget.max_wall_seconds` | int ≥1 | yes | Hard cap on wall time. |
| `budget.max_tool_calls` | int ≥1 | yes | Hard cap on tool invocations. |

## 3. Return envelope

The child MUST return a single JSON document shaped as below. Free-form narrative goes into the
findings' `detail` fields; the envelope itself is machine-parsable.

```json
{
  "agent_id": "0196f34a-8c7e-7b2f-9d01-3e8a9b4c2f11",
  "verdict": "⚠️ ISSUES FOUND (iter 1)",
  "findings": [
    {
      "severity": "S1",
      "title": "Null-pointer on empty cart clear",
      "location": "apps/api/src/ingredients/ingredients.service.ts:83",
      "detail": "clearList(orgId) dereferences list.items[0].id when empty. Repro: fresh org. FIX: early-return on length 0."
    },
    {
      "severity": "S3",
      "title": "Missing @ApiOperation on DELETE /ingredients/:id",
      "location": "apps/api/src/ingredients/interface/ingredients.controller.ts:54",
      "detail": "ADR-002 mandates summary + description on every endpoint."
    }
  ],
  "telemetry": {
    "ai_playbook.review.layer": "acceptance",
    "ai_playbook.tokens_in": 8412,
    "ai_playbook.tokens_out": 3301,
    "ai_playbook.tool_calls": 14,
    "ai_playbook.wall_seconds": 92,
    "ai_playbook.write_paths_touched": []
  },
  "budget_consumed": {
    "tokens": 11713,
    "wall_seconds": 92,
    "tool_calls": 14
  }
}
```

### 3.1 Field reference

| Field | Type | Req | Notes |
|---|---|---|---|
| `agent_id` | UUIDv7 | yes | Echoes the spawn envelope. |
| `verdict` | enum string | yes | Exactly one of the literals in [verdict-contract.md](verdict-contract.md) §1. |
| `findings` | array | yes | Empty `[]` iff verdict is `✅ APPROVED`. |
| `findings[].severity` | `S1`..`S4` | yes | `S0` rejected per verdict-contract §2.1. |
| `findings[].title` | string | yes | ≤80 chars; identity used by the max-2-rework rule. |
| `findings[].location` | string | yes | `path:line` or symbolic (e.g. `mcp-servers.yaml:servers.hindsight`). |
| `findings[].detail` | string | yes | WHY / WHERE / FIX per [error-message-standard.md](error-message-standard.md). |
| `telemetry` | object | yes | OTel span attributes the parent MUST carry forward. |
| `budget_consumed` | object | yes | Actuals; used by retros to tune budgets. |

### 3.2 Special verdict `budget_exhausted`

If the harness hits any budget limit before the child emits its envelope, it synthesises this
return:

```json
{
  "agent_id": "...",
  "verdict": "⚠️ ISSUES FOUND (iter 1)",
  "findings": [
    {
      "severity": "S2",
      "title": "Subagent budget_exhausted",
      "location": "agent_contract:budget",
      "detail": "Hit max_tool_calls=40 before envelope emitted. WHY: likely infinite_loop; see agentic-failures.md. FIX: inspect trace, tighten brief or raise budget. OVERRIDE: --force-with-reason for the retry only."
    }
  ],
  "telemetry": { "ai_playbook.failure.kind": "budget_exhausted" },
  "budget_consumed": { "tokens": 50000, "wall_seconds": 301, "tool_calls": 40 }
}
```

Rationale: the parent's triage logic is uniform; no separate failure path.

## 4. Worked examples

### 4.1 Reviewer pair (Acceptance Auditor)

**Input** — spawned by the `bmad-code-review` skill in consumer-c-legacy:

```json
{
  "agent_id": "0196f400-0000-7000-8000-000000000010",
  "agent_type": "reviewer",
  "parent_agent_id": "0196f400-0000-7000-8000-000000000001",
  "trace_id": "bd7a9a0f6e5240cda0f60fc94d5f12ab",
  "scope": {
    "project": "consumer-c-legacy",
    "change_id": "module-1-ingredients-implementation",
    "read_paths": ["apps/api/src/ingredients/**", "openspec/changes/module-1-ingredients-implementation/**"],
    "write_paths": []
  },
  "memory": { "bank_id": "consumer-c-legacy", "recall_depth": 5 },
  "brief": "Acceptance Auditor. Walk AC 1..12 in specs/ingredients.md. For each, cite test or code evidence. Verdict per verdict-contract.md. Do NOT read design.md (context isolation).",
  "budget": { "max_tokens": 25000, "max_wall_seconds": 240, "max_tool_calls": 40 }
}
```

**Return** — clean approval:

```json
{
  "agent_id": "0196f400-0000-7000-8000-000000000010",
  "verdict": "✅ APPROVED",
  "findings": [],
  "telemetry": {
    "ai_playbook.review.layer": "acceptance",
    "ai_playbook.tokens_in": 6140,
    "ai_playbook.tokens_out": 1820,
    "ai_playbook.tool_calls": 11,
    "ai_playbook.wall_seconds": 74
  },
  "budget_consumed": { "tokens": 7960, "wall_seconds": 74, "tool_calls": 11 }
}
```

### 4.2 Builder pair (writes code)

**Input** — task 3.2 of an applied OpenSpec change:

```json
{
  "agent_id": "0196f411-0000-7000-8000-000000000020",
  "agent_type": "builder",
  "parent_agent_id": "0196f411-0000-7000-8000-000000000001",
  "trace_id": "77cc01e5b3f44e9681d3a0edf1a3c8b4",
  "scope": {
    "project": "consumer-c-legacy",
    "change_id": "module-1-ingredients-implementation",
    "read_paths": ["apps/api/src/ingredients/**", "packages/types/src/**"],
    "write_paths": [
      "apps/api/src/ingredients/domain/**",
      "apps/api/src/ingredients/application/**",
      "apps/api/test/ingredients/**"
    ]
  },
  "memory": { "bank_id": "consumer-c-legacy", "recall_depth": 3 },
  "brief": "Implement task 3.2 of tasks.md: domain entity Ingredient + value object UnitOfMeasure + use case CreateIngredient. TDD — red test first. Respect ADR-001 (no cross-context imports). Return `write_paths_touched` listing exactly the files you modified.",
  "budget": { "max_tokens": 80000, "max_wall_seconds": 600, "max_tool_calls": 80 }
}
```

**Return** — implemented + self-review:

```json
{
  "agent_id": "0196f411-0000-7000-8000-000000000020",
  "verdict": "✅ APPROVED",
  "findings": [],
  "telemetry": {
    "ai_playbook.tokens_in": 14820,
    "ai_playbook.tokens_out": 9100,
    "ai_playbook.tool_calls": 42,
    "ai_playbook.wall_seconds": 318,
    "ai_playbook.write_paths_touched": [
      "apps/api/src/ingredients/domain/ingredient.entity.ts",
      "apps/api/src/ingredients/domain/unit-of-measure.value-object.ts",
      "apps/api/src/ingredients/application/create-ingredient.use-case.ts",
      "apps/api/test/ingredients/create-ingredient.spec.ts"
    ]
  },
  "budget_consumed": { "tokens": 23920, "wall_seconds": 318, "tool_calls": 42 }
}
```

The parent agent now verifies that `write_paths_touched` ⊆ `scope.write_paths`. Any file outside
the scope is surfaced as an `untracked_state_mutation` and the builder's verdict is downgraded
regardless of what it self-reported.

## 6. RBAC linkage

At the k3s deployment layer (T18 LangGraph workflows, not in scope for this spec), each
`scope.write_paths` glob set maps to a ServiceAccount role. The harness refuses to spawn a child
whose requested `write_paths` exceed the parent's ServiceAccount. The ADR that pins this mapping is
owned by T18; this spec only guarantees the envelope's shape.

## 7. Budget enforcement

The harness is authoritative. On any of `tokens ≥ max_tokens`, `wall_seconds ≥ max_wall_seconds`,
`tool_calls ≥ max_tool_calls` it:

1. Interrupts the child.
2. Synthesises the `budget_exhausted` return (§3.2).
3. Emits an OTel span with `ai_playbook.failure.kind=budget_exhausted` for retro surfacing.

An agent that "knows" it is close to the limit and wraps up voluntarily is welcome to, but the
authority is the harness — never the model's self-report.
