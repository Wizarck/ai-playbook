# Rule use-cases matrix

## Why

The L1 / L2 / L3 paired-enforcement model (see [enforcement-layers.md](enforcement-layers.md)) ships 38 rules under `docs/rules/`. Each rule binds four artefacts via a shared slug: the markdown contract (L2), the Python hardrule (L1), the test fixtures, and the GitHub Actions workflow (L3). This matrix collapses the fleet into a single reference table — one row per rule — so a reader can see at a glance how a rule fires, what it binds the agent to, where the server-side gate lives, and (once telemetry data is collected) how often consumers obey it in practice.

## What

The columns are:

- **Slug** — links to the rule contract under `docs/rules/`.
- **Status** — `enforced` / `warn` / `advisory` per the rule frontmatter (D18 lifecycle).
- **L1 trigger** — the first sentence of the rule's `## Trigger` section, summarising when the hook fires.
- **L2 binding clause** — the RFC 2119 imperative from the rule's `## Binding clause` section (verb extracted).
- **L3 workflow** — the GitHub Actions workflow that gates merge. Rules without a dedicated workflow ride the shared `check-rule-schemas.rule.yml` job that validates the rule frontmatter + paired hardrule existence.
- **Live obey-rate** — placeholder for the obey-rate-per-rule-per-LLM metric defined in [telemetry-design.md](telemetry-design.md). First real data lands one week after consumer adoption of v0.18.3.

The matrix is auto-derivable from the rule corpus (frontmatter + `## Trigger` + `## Binding clause`) via a `gen_indexes.py` extension; v0.18.3 ships it hand-curated and refreshes it whenever a rule lands.

## Concrete example

The `cleanup-zombies` row pairs `scripts/rules/cleanup-zombies.rule.py` (L1) with `docs/rules/cleanup-zombies.rule.md` (L2) and `.github/workflows/cleanup-zombies.rule.yml` (L3). When v0.18.3 ships and telemetry accumulates a week of fires, the row's `Live obey-rate` column flips from `—` to e.g. `99.2% (Claude, n=487) / 96.4% (Cursor, n=141) / — (Gemini)`. A drop in obey-rate signals either rule under-spec or LLM drift, per arXiv 2310.13361 ([academic-foundations.md](academic-foundations.md) source 13).
